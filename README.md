One line: the funniest git commit message an AI coding agent writes right
before it breaks production on a Friday.

> I skipped staging and ran purge_users.sql on 82,000 live rows, Friday 4:58pm. Good news: zero users are inactive anymore.

Entry for the [Ship It Friday](https://make.fun/bounty/u-mgwals-ship-it-friday-30bd407a)
bounty on [make.fun](https://make.fun) — free entry, one winner, $2.

## How it works

`main.py` writes the single line to `/output/entry.txt` (121 characters,
inside the 1–159 character gate, 76% of the limit — the winners' sweet spot
for one-liners). No dependencies, no network, deterministic: the same line
every run, verified twice before submitting.

```sh
python3 main.py
```
